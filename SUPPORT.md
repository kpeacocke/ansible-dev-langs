# Support

Start with the [README](README.md), especially the requirements, configuration,
platform support, and troubleshooting sections.

For a reproducible project problem, open an issue with:

- the operating system and architecture;
- Ansible and collection versions;
- the relevant `dev_languages` entry with secrets removed;
- the complete error message; and
- the command and smallest reproduction that trigger the problem.

For security concerns, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue. Please do not request help with private infrastructure details in
public discussions.
